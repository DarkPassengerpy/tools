ℹ️ ¿Qué es "Calculá tu pedido"?

“Calculá tu pedido” es una herramienta sencilla para organizar pedidos grupales. Se ingresa lo que cada persona quiere y el sistema suma automáticamente las cantidades, mostrando un resumen claro de todo lo que se pidió. Así se evita confusión y se asegura que cada pedido quede registrado de forma ordenada.
